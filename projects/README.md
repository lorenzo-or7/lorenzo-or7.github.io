# projects/

Pasta opcional para hospedar **demos** dos projetos junto com o portfólio.

Exemplo: coloque o build do conceito "Maçã Padaria Artesanal" em
`projects/maca/index.html` e, em `js/data.js`, defina:

```js
links: { demo: "projects/maca/", github: "https://github.com/seu-usuario/maca" }
```
