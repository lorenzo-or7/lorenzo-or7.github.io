# assets/icons/

- `favicon.svg` e `apple-touch-icon.png` → ícones do site.
- Logos das tecnologias (fundo transparente, 256×256 WebP; o site as exibe sobre um "azulejo" claro):
  `html5.webp`, `css3.webp`, `javascript.webp`, `php.webp`, `mysql.webp`,
  `git.webp`, `github.webp`, `astah.webp`, `python.webp`, `db-modeling.webp`, `requirements.webp`, `software-modeling.webp`.
  Para trocar, substitua o arquivo mantendo o nome, ou altere o campo `icon`
  em `TECHNOLOGIES` (js/data.js). Tecnologias sem `icon` exibem uma sigla.
