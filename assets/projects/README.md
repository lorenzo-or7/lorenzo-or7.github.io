# assets/projects/

Uma pasta por projeto (ex.: `votai/`, `casa-di-lucente/`, `maca/`, `iguana/`, `chapula/`).

- Capa: `cover.webp` (recomendado 1600×820 para destaque, 1280×800 para conceitos)
- Screenshots do estudo de caso: `busca.webp`, `comparacao.webp`...
- Vídeo curto (conceitos): `preview.mp4` (sem áudio, poucos segundos, < 3 MB)

Depois, aponte os caminhos em `js/data.js` (`image`, `video`, `caseStudy.screenshots`).
Sem imagem, o site exibe uma prévia ilustrada com as cores definidas em `placeholder`.
