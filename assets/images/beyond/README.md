# assets/images/beyond/

Imagens opcionais da seção "Além do Código" (Beyond Code).

Exemplos: `music/travis-scott.webp`, `games/lol.webp`, `anime/aot.webp`.
Formato quadrado pequeno (~80×80, WebP). Depois preencha o campo `image`
do item em `PERSONAL_INTERESTS` (js/data.js). Sem imagem, aparece só o texto.
